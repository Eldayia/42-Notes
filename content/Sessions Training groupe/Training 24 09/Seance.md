# Training du 24/09

[Accueil public](../../index.md) · [Toutes les séances](../Sessions.md)

## Objectif

Pratiquer les chaînes, les arguments, l'allocation dynamique et les pointeurs de pointeurs en C.

## Exercices dans l'ordre

| Exercice | Notion |
| --- | --- |
| [ex0 - ft_strlen](ex0%20-%20ft_strlen.md) | Compter une chaîne |
| [ex1 - ft_putstr](ex1%20-%20ft_putstr.md) | Afficher une chaîne |
| [ex2 - ft_strcpy](ex2%20-%20ft_strcpy.md) | Copier une chaîne |
| [ex3 - argc & argv](ex3%20-%20argc%20&%20argv.md) | Afficher les arguments |
| [ex4 - ft_print_strs](ex4%20-%20ft_print_strs.md) | Parcourir un tableau de chaînes |
| [ex5 - ft_strdup](ex5%20-%20ft_strdup.md) | Dupliquer une chaîne |
| [ex6 - ft_range](ex6%20-%20ft_range.md) | Allouer un tableau d’entiers |
| [ex7 - ft_swap_str](ex7%20-%20ft_swap_str.md) | Échanger deux pointeurs |

## Déroulement proposé

1. Lire l'objectif et les prérequis de l'exercice.
2. Chercher individuellement, puis comparer les approches en binôme.
3. Compiler et tester la solution, notamment les entrées vides et les bornes lorsque l'énoncé les prévoit.
4. Ouvrir les indices ou la correction selon le besoin.
5. Expliquer au groupe ce que manipule chaque pointeur avant de passer à la suite.
